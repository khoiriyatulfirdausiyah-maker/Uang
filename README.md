# UangKu v8.15 Performance Final - Android

Full Android WebView project containing UangKu v8.15.

## Build APK with GitHub Actions
1. Upload ALL files and folders in this project to the root of a GitHub repository.
2. Open the repository's **Actions** tab.
3. Open **Build UangKu APK**.
4. Run the workflow (or push to main/master to build automatically).
5. After success, download artifact **UangKu-v8.15-debug-apk**.
6. Extract it to get `app-debug.apk`.

Main web app:
`app/src/main/assets/index.html`

Package name:
`com.uangku.app`
